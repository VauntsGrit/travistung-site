# travistung.com static landing page

This package is a GitHub Pages-ready static site for travistung.com.

## Contents
- `index.html`
- `style.css`
- `script.js`
- `.nojekyll`
- `assets/alpine.png`

## Notes
- `www.travistung.com` should already be configured in GoDaddy as a CNAME to your GitHub Pages username.
- If the repository is already live, you can replace the repository contents with these files and GitHub Pages will redeploy automatically.
- To change the quote later, edit the text inside `index.html`.
- To change the background later, replace `assets/alpine.png` while keeping the same filename.
